# Lista CSS 1 - Programação para Internet

Atividades de CSS, seletores, display, position e animações.

Os arquivos foram organizados separadamente e podem ser abertos pelo `index.html`.

- Atividade 0: acessar https://flukeout.github.io/ e realizar o jogo CSS Diner. A realização do jogo depende do aluno.
- Atividades 1, 2, 3 e 4: conceitos, exemplos e seletores.
- Atividade 5: não aparece no PDF enviado.
- Atividade 6: exemplos 6a, 6b e 6c.
- Atividade 7: layout de chat (somente HTML e CSS; botão sem envio real).
- Atividade 8: bandeiras desenhadas apenas com HTML/CSS.
- Atividade 9: layout de perfil com avatar ilustrativo em CSS.
- Atividade 10: animação de barquinho e nuvem em CSS; barco em imagem SVG local de fundo, conforme pedido.

Para publicar no repositório `programacaoweb`, coloque esta pasta na raiz do repositório e faça commit/push.

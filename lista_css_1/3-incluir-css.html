Atividade 3 - Como incluir CSS no HTML?

Existem três maneiras:

  1. Inline: direto na tag, usando style. Exemplo: <p style="color: red;">Texto</p>
  2. Interno: dentro da tag <style> no head do HTML.
  3. Externo: em um arquivo .css separado, ligado com <link rel="stylesheet" href="estilo.css">.

O CSS externo é bom quando várias páginas usam os mesmos estilos.

Explicação

Quando várias regras atingem o mesmo elemento, a que tem maior especificidade costuma vencer.

ItemCor finalMotivo
AbacaxiVermelhoRegra 1, que seleciona todos os li.
MelãoCinzaRegra 3, porque tem a classe fruta.
PeraAzulRegra 6, pois o id lip2 tem prioridade sobre a classe.
UvaLaranjaRegra 7, que combina id lip3 e classe fruta.
MaçãCinzaRegra 3, classe fruta.
CarnePretoRegra 4, li vizinho de outro li e classe churras.
LinguiçaPretoRegra 4, pelo mesmo motivo.
Pão de alhoMagentaRegra 5, classe churras junto do atributo draggable=true.

A regra 2 deixa os itens churras verdes se não houver uma regra mais específica. A regra 8 não é aplicada, pois não existe um elemento com id lip5.

Internet e Web não são a mesma coisa

A Internet é a infraestrutura global de redes que troca dados usando protocolos como TCP/IP.
A Web é um dos serviços que funciona sobre a Internet.
Na Web, navegadores acessam páginas e recursos oferecidos por servidores, geralmente por HTTP ou HTTPS.

Sequência recomendada de leitura

  1. Entenda a história da Web
  2. Aprenda como funciona o HTTP
  3. Consulte a página de estados
  4. Veja um currículo em HTML
  5. Experimente um formulário de contato

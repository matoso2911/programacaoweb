# Lista 1 — HTML, Web, HTTP e Publicação

Atividades de Programação para Internet — professor Romulo Beninca.

## Como usar

Abra `index.html` no navegador e navegue pelos links.

## Páginas

- `index.html` — portal inicial e menu de navegação (atividade 1)
- `historia_web.html` — história da Internet e Web, tabelas, imagens e fontes (atividade 2)
- `http.html` — requisições, respostas e códigos HTTP (atividade 3)
- `curriculo.html` — currículo fictício, seções, contatos e horários (atividade 4)
- `contato.html` — formulário demonstrativo, sem backend (atividade 5)
- `estados.html` — página adicional criada porque o menu exigido na atividade 1 inclui "Estados"
- `imagens/` — imagens SVG locais, usadas em tags `<img>`

## Antes de entregar

- Substitua `SEU NOME` e a turma no comentário de `index.html`.
- Personalize o currículo fictício se desejar; os dados de exemplo não são informações reais.
- Os links externos e SVGs não dependem de CSS.
- O formulário valida os campos no navegador, mas **não envia mensagens a nenhum servidor**.
- Confirme que todos os links estão funcionando após publicar no GitHub Pages.
- A atividade 6 exige também postar no Moodle o link do repositório e um comentário sobre a experiência.

**Nota sobre o enunciado:** a atividade 5 menciona `3_curriculo.html`, mas o arquivo da atividade 4 é `curriculo.html`; foi usada a segunda forma para manter o link funcional.

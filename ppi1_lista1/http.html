O que é HTTP?

HTTP (Hypertext Transfer Protocol) é um protocolo usado para a comunicação entre cliente e servidor na Web. O navegador atua como cliente: envia uma requisição e recebe uma resposta do servidor.

Cliente, servidor, requisição e resposta

Cliente
Programa que solicita um recurso, como o navegador.
Servidor
Programa que recebe requisições e devolve recursos ou mensagens.
Requisição
Mensagem com método, caminho, cabeçalhos e, em alguns casos, corpo.
Resposta
Mensagem com código de status, cabeçalhos e, muitas vezes, conteúdo.

Métodos GET e POST

  • GET: solicita a representação de um recurso; dados de formulários GET costumam aparecer na URL.
  • POST: envia dados para serem processados pelo servidor, normalmente no corpo da requisição.

Exemplo de requisição HTTP

GET /index.html HTTP/1.1
Host: exemplo.com
Accept: text/html

Exemplo de resposta HTTP

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8

<!DOCTYPE html>
<html><body>Olá!</body></html>

Códigos de status

CódigoSignificado
200OK — requisição atendida
301Moved Permanently — redirecionamento permanente
302Found — redirecionamento temporário
400Bad Request — requisição inválida
403Forbidden — acesso negado
404Not Found — recurso não encontrado
500Internal Server Error — erro interno no servidor

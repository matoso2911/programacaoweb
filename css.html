CSS

CSS é uma linguagem declarativa auxiliar de documentos HTML para estilização de definição de comportamento. O CSS pode ser declarado de três formas distintas.

  1. Na tag style, definida no cabeçalho do HTML.
  2. Em um documento externo por meio da tag link.
  3. Inline no próprio elemento HTML.

CSS possui diversas formas de selecionar em quais elementos HTML uma regra será aplicada.

Seletores
  • Seletores de tipo: selecionam elementos pelo nome da tag.
  • Seletores de classe: selecionam elementos pela classe CSS.
  • Seletores de ID: selecionam um único elemento pelo ID.
